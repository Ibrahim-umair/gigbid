# GigBid (live demo)

A LangGraph multi-agent freelancer copilot: it screens jobs from a simulated marketplace
(GigSim), drafts evidence-grounded proposals and waits for your approval before anything is
sent. Source, results and report: https://github.com/Ibrahim-umair/gigbid

Sign in with the reviewer credentials provided privately. State resets when the Space restarts.
